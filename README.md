# dealer-evaluation-backend

## Project Name
Cars Dealership – Full Stack Application Development Capstone Project

## Description
A full-stack web application for Cars Dealership, a national car retailer in the United States.

The application allows users to explore dealership branches, view dealer information, register and log in, and submit dealership reviews.
